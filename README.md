# Dally Ramírez — Portfolio

Portafolio personal desarrollado con React y Vite. El despliegue se realiza automáticamente en GitHub Pages utilizando GitHub Actions.

🔗 **Live:** https://dallycita.github.io/portafolio-web/

## Stack

* React 18
* Vite 5
* CSS Modules
* GitHub Actions (CI/CD)

## Desarrollo local

```bash
npm install
npm run dev
```

## Reflexión

### ¿A qué audiencia está dirigido este portafolio?

Este portafolio está pensado para personas que trabajan en desarrollo frontend y para empresas que buscan desarrolladores web. La idea principal fue mostrar no solo proyectos terminados, sino también la forma en que pienso al momento de diseñar y desarrollar una solución.

Quise que el sitio reflejara buenas prácticas de organización, una estructura clara y proyectos que demuestran tanto conocimientos técnicos como capacidad para resolver problemas. Más que enfocarme únicamente en las tecnologías utilizadas, intenté mostrar cómo aplicarlas en situaciones reales.

Uno de los aspectos más importantes fue incluir proyectos donde pudiera demostrar lógica, organización del código y diseño de interfaces, ya que considero que esos son aspectos que suelen evaluarse en procesos de contratación.

### ¿Qué tecnologías elegí usar y por qué?

**React + Vite para el portafolio**

Elegí React porque es una de las tecnologías más utilizadas actualmente en desarrollo frontend y porque me permite crear componentes reutilizables de forma sencilla. Vite fue la herramienta elegida porque facilita mucho el desarrollo y ofrece tiempos de carga rápidos.

**CSS Modules**

Decidí utilizar CSS Modules para mantener los estilos organizados y evitar conflictos entre clases. Además, me permitió trabajar con CSS tradicional sin depender de frameworks adicionales.

**JavaScript Vanilla para algunos proyectos**

En varios proyectos preferí trabajar con JavaScript puro para demostrar que entiendo los fundamentos del lenguaje y no dependo completamente de frameworks. Esto me ayudó a practicar conceptos como módulos, manejo de eventos y organización de código.

**GitHub Actions**

Implementé GitHub Actions para automatizar tareas como la instalación de dependencias, la ejecución de pruebas y el despliegue del sitio. De esta forma, cada cambio que se sube al repositorio sigue un proceso automático antes de publicarse.

### ¿Qué tecnología del curso decidí no usar y por qué?

Decidí no utilizar **Next.js**.

Aunque es una herramienta muy popular y tiene muchas ventajas, consideré que para este proyecto no era necesaria. El portafolio es un sitio estático que no maneja datos dinámicos ni funcionalidades que requieran renderizado del lado del servidor.

Por esa razón preferí mantener una solución más simple utilizando React y Vite. Considero que es importante elegir las herramientas según las necesidades del proyecto y no agregar tecnologías que realmente no aportan valor en ese contexto.

### ¿Dónde me arriesgué y dónde la jugué seguro?

La parte donde más me arriesgué fue en algunos proyectos donde implementé funcionalidades complejas sin depender de librerías externas. Esto me permitió aprender más sobre cómo funcionan ciertas herramientas internamente y enfrentar problemas técnicos que no siempre tienen una solución inmediata.

Por otro lado, fui más conservador con el diseño visual del portafolio. Preferí una interfaz limpia, sencilla y fácil de navegar antes que agregar demasiados efectos o animaciones que pudieran afectar la experiencia del usuario o distraer del contenido principal.

### Si tuviera otra semana, ¿qué mejoraría?

Una de las áreas que mejoraría sería la experiencia en dispositivos móviles. Aunque el sitio funciona correctamente en diferentes tamaños de pantalla, todavía hay detalles que podrían optimizarse para que la navegación sea más cómoda.

También me gustaría migrar completamente el portafolio a TypeScript para tener un mejor control de tipos y hacer el proyecto más consistente con otras aplicaciones que he desarrollado.

Finalmente, dedicaría más tiempo a agregar nuevas funcionalidades interactivas y mejorar algunos detalles visuales para que la experiencia sea más atractiva sin perder simplicidad.
