# Dally Ramírez — Portfolio

Portfolio personal construido con React + Vite. Deploy automático en GitHub Pages via GitHub Actions.

🔗 **Live:** https://dallycita.github.io/portafolio-web/

## Stack

- React 18
- Vite 5
- CSS Modules
- GitHub Actions (CI/CD)

## Desarrollo local

```bash
npm install
npm run dev
```
